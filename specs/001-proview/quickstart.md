# 快速开始：ProView 开发

**特性**：`001-proview`  
**环境**：Windows 10/11，**Visual Studio 2019**（安装「通用 Windows 平台开发」工作负载）。

---

## 1. 创建 UWP 项目（若仓库尚无 `src/ProView`）

1. 打开 VS2019 → **创建新项目** → 选择 **空白应用(通用 Windows)**。  
2. 项目名称建议：`ProView`；位置：`ProView\src\`。  
3. **最低版本**选择 **Windows 10 版本 1903 (内部版本 18362)** 或与你目标 **19041** 一致的 SDK（以实现规格 MinVersion 为准，可在创建后编辑 `Package.appxmanifest`）。  
4. 目标版本选当前已安装的较新 Windows 10/11 SDK。

---

## 2. 配置清单要点

- 在 `Package.appxmanifest` 中：  
  - 声明需要 **图片文件类型关联**（根据实现勾选扩展名）。  
  - 按需启用 ** broadFileSystemAccess**（宽泛文件访问），并阅读 Store 策略与用户说明。  
- 确认应用显示名称、包名与发布用证书（侧载/商店后续再定）。

---

## 3. 生成与运行

1. 选择 **x64** 或 **ARM64**（与目标机一致）。  
2. **F5** 本地调试；首次验证：从「示例图片」或测试目录通过「打开方式」启动（关联配置完成后）。

---

## 4. 与规格对齐的冒烟顺序

1. 打开单张图片 → 可见首帧。  
2. 同目录多张 → 方向键切换 + 首尾循环。  
3. 滚轮缩放 + 指针锚点。  
4. 任务管理器：静态画面时空载 CPU 接近 0%。  
5. 发布目录查看 `.msix` / `.appx` 大小是否满足 ≤5MB（Release + .NET Native）。
